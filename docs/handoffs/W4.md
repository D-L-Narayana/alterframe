## Coordinate / orientation agreement (implemented and pixel-tested)

* **Display space = mirrored intrinsic-video normalized space.** The entire pipeline runs at `internalSize(videoW, videoH, renderScale)` in that space. The canvas backing store is `css × min(dpr, quality.maxDpr)`; the present pass applies **one** `coverFit(video → canvas)` and samples the composite *and the HUD* through the same mapping, so nothing is stretched and overlays stay aligned at 16:9, 1:1, 9:16 (tested at 640×360, 360×360, 180×320@2x, 640×200).
* **Mirroring happens once**: the ingest pass flips the video UV when `inputs.mirrored`. Mask, quad, persona overlay/backdrop and HUD are consumed as-is (already mirrored by W3/W6/W7/W8). Tested: video dot at source (0.75,0.3) + overlay dot at display (0.25,0.3) coincide when mirrored; the mask quadrant test passes identically with `mirrored` on/off.
* **No y flips anywhere except present.** All uploads use `UNPACK_FLIP_Y = false` (texel row 0 = top), FBO targets keep row 0 = display top (`v_uv = clip*0.5+0.5`), quad corners map linearly to clip (`displayToClip`), and the present pass flips once for the default framebuffer. Tested with the quadrant video (TL red / BR white upright).
* Overlay canvases may have any pixel size (W2 sizes them to the video frame); they are sampled by normalized uv, so a video-aspect overlay is pixel-exact and never distorted.
* `u_backdrop` defaults to 1×1 `PERSONA_TOKENS.paperWhite` when `personaBackdrop` is null; `u_mask` defaults to 1×1 `1.0` ("all person") when no segmentation; overlay/HUD default to transparent.
* Mask formats: `R32F` with `OES_texture_float_linear` (SwiftShader has it), else `R8` (float→byte, linear filtering). `SegmentationResult.texture` is ignored (it lives in MediaPipe's own context) — CPU `Float32Array` path only, as in lead-checklist B3. Re-upload is skipped when `tracking.t` is unchanged and the same array instance is passed (tracker did not run).

## Pipeline details

1. Upload raw video (`texImage2D` each frame; `RGBA8`). If `sourceReady` is false the canvas is cleared to black.
2. Ingest pass → `videoTex` (display space, internal res). `u_video` for all passes is this texture.
3. `baseStyle` passes (if any) via `PassRunner.run` (ping-pong targets from `TargetPool`, `pass.scale` honoured, `u_resolution/u_texel/u_time` + `pass.uniforms(ctx)` with `ctx.width/height` = that pass's size).
4. `windowStyle` passes → `winTex` (only when `quad?.visible && opacity > 0`).
5. Composite target: base copy, then the quad drawn as two triangles (TL,TR,BR)+(TL,BR,BL) with the window shader: `window ⊕ personaOverlay` (straight alpha), glitch (per-scanband UV shift, RGB split, grain; only when `u_glitch > 0`; time-quantised at 24 Hz), alpha = `quad.opacity`, blend `SRC_ALPHA/ONE_MINUS_SRC_ALPHA`. Hard edges, no feather, no minimum area (a 2 px slit renders — tested). Bow-tie corner orders render as the two-triangle fan without throwing.
6. Present: cover-fit + y flip + HUD over everything. Alpha written as 1.
7. `stats.passes` = draws this frame; `stats.lastFrameMs` = CPU submission time (no `gl.finish`).

Context loss: `webglcontextlost` → `preventDefault`, renders become no-ops (`stats.passes = 0`); `webglcontextrestored` → a fresh `Compositor` (programs, pool, textures) and all sources re-upload regardless of `__dirty`. Tested with `WEBGL_lose_context`.

Dirty flags: `__dirty === false` skips the upload; `true` uploads and resets to `false`; absent → upload every frame. Backdrop and HUD canvases are handled the same way.

## Known gaps / notes

* Render targets are RGBA8 (no float intermediates); fine for the colour passes planned by W5.
* Glitch is applied to the window *content* (uv shift inside the slit), not to the quad outline — matches the "illustration seen through a slit" reading. The runtime decides when `glitch > 0` (lead: default off).
* Overlay compositing uses straight alpha from Canvas2D (`UNPACK_PREMULTIPLY_ALPHA = false`); W6/W8 should draw with normal (non-premultiplied) canvases, which is the default.
* `internalSize` caps the long side at 1920 px; `backingSize` does not cap (canvas = what the user sees). On a 3× phone W2 should pass `quality.maxDpr ≤ 2` (already in `DEFAULT_QUALITY`).
* The GPU tests need Chromium from Playwright; when it cannot launch they skip with a reason rather than fail (CI must run `npx playwright install chromium` before `npm test` for them to execute).
* `compilePass` returns `{ ok, log }` only; uniform-coverage checks (uniforms referenced vs provided) are left to W5's static tests.
