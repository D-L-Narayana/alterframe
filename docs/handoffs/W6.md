## Exported API

```ts
import { createPersonaLayer } from '@/render/persona';
const layer = createPersonaLayer();            // contract signature works as-is
layer.resize({ width, height });               // VIDEO-FRAME size in device px (lead-checklist #12)
layer.update(frame, scene, t);                 // repaints only on input change
layer.overlay / layer.backdrop                 // HTMLCanvasElement | OffscreenCanvas, carry __dirty
layer.personaId
// W6 extensions (superset, optional for the runtime):
createPersonaLayer({ reducedMotion?: boolean; createCanvas?: PersonaCanvasFactory; seed?: number })
layer.setReducedMotion(v)                      // runtime should mirror settings.reducedMotion each frame/when changed
layer.invalidate()                             // force repaint (e.g. after GL context restore)
```

`__dirty` protocol: layer sets `true` when it repaints; W4 uploads and sets `false`. If W4 ignores the flag it uploads every frame (contract-compatible).

## Behaviour

* **Backdrops** (opaque): `portrait` paper white + procedural fibre grain + vignette (static); `masked` navy→magenta sky, 16 skyscrapers in 2 parallax layers (9 far @0.0035 w/s, 7 near @0.008 w/s) with lit windows, 9 neon streaks (blue/magenta, glow+core) drifting at 0.0055 w/s, ground reflection band — animated at 30 Hz ticks, **frozen (identical to t=0) under reduced motion**; `suit` warm paper (3.5 % pink tint) with diagonal halftone lattice (static).
* **Portrait overlay**: iris accent ellipse 1.35× eye width (brown `#5a3a1a` core, ink rim, pupil, two gloss highlights, upper-lid ink arc) oriented by `roll`; alpha and vertical radius fade with `eyeOpen*` (smoothstep 0.15→0.75, fully gone at ≤ 15 %); cheek blush radial ellipses at landmarks 425/205; lip tint = outer lip ring polygon at 55 %.
* **Masked overlay**: face oval (36 contract indices, ×1.04) filled `lensWhite` at 92 % with radial rim shading + magenta lining glow, 1.5 px rim line; two **opaque** teardrop lenses (`lensShape`, span ≈ 1.9× eye width ×1.12, tip towards the temple tilted 0.38 rad up, rotated by roll), 4 px (at 720 p) magenta→pink gradient outline, inner highlight line. Per errata §4b.3: **no eye cut-outs**.
* **Suit overlay**: torso polygon from the 19-point jaw line (hugs the chin at any roll) → neck → level shoulders 1.6× face width → canvas bottom; black hood/jacket, pink suit panel, white chest panel, web (20 spokes + sagging threads, 1 px white 70 %) clipped to pink-only (even-odd), black collar band under the jaw, seams, original spider crest spanning 1.1× face width (white with black outline so it reads on the white panel). Overlay alpha 0.88 ≤ 0.9.
* **Alignment**: every shape is built from the frame's landmarks in px (`x*width, y*height`); `roll` only orients ellipses/lenses, so overlays stay registered to the face under roll (verified with landmark dots in the harness at ±25°).
* **Dirty tracking**: overlay signature = persona + size + ~120 quantized landmark coords (0.0005 norm ≈ 0.6 px) + roll/eyeOpen/mouthOpen/smile buckets; never depends on `t`. Backdrop signature = persona + size (+ 33 ms tick for masked when motion allowed). Face lost → one clear, then idle.
* **Performance** (headless Chromium, SwiftShader, 1280×720): overlay repaint 0.5–1.8 ms; backdrop tick 0.2–0.4 ms after prerender (was 67 ms before layer caching). City layers are cached in a single module-level slot keyed by size+seed (one layer per app assumed).

## Known gaps / tuning suggestions

1. Torso shoulders are exactly 1.6× face width per contract; real shoulders are ~2.5× so the user's own clothing shows beside the suit (consistent with errata §4b.7). Raise `TORSO.shoulderHalf` if the lead prefers full coverage (test in `geometry.test.ts` pins 1.6).
2. Hands are not overlaid (contract §W6.4).
3. `prefers-reduced-motion` is auto-detected only at creation; the runtime should call `setReducedMotion(settings.reducedMotion)` so the store setting wins.
4. The masked mask covers the full face oval including the mouth (errata: treat as full mask); hair/hood are untouched.
5. Visual baseline for W10 `visual.spec.ts`: art is deterministic (seed 5) — safe to snapshot; parallax means masked screenshots must use a fixed `t` or reduced motion.
6. The procedural look is an approximation of the reference's hand-drawn style, not a reproduction.
