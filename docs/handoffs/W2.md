## 2. Exported API

### `@/media`
```ts
createCameraSource(opts: CameraOptions = {}, env?: Partial<MediaEnv>): CameraSource
interface CameraSource extends ObservableFrameSource {
  kind: 'camera'; stream: MediaStream | null; deviceId: string | null;
  listDevices(): Promise<MediaDeviceInfo[]>;          // videoinput only; enumerated right after permission (labels populated), cached
}
createFileSource(file: File | Blob | string, env?): FileSource
interface FileSource extends ObservableFrameSource {
  kind: 'file'; url: string; play(): Promise<boolean>; pause(): void; paused: boolean; // facingMode 'user' → mirrored like a selfie cam
}
interface ObservableFrameSource extends FrameSource { error: string | null; onStatus(cb: (status, error) => void): () => void }
class MediaSourceError extends Error { status: 'denied' | 'unavailable' | 'error'; cause: unknown }
classifyGetUserMediaError(err): { status, message }; buildCameraConstraints(opts, relaxed?)
isObservableSource / isCameraSource / isFileSource; createFrameClock; defaultMediaEnv / resolveMediaEnv
```
Behaviour:
* Status: `idle → requesting → ready | denied | unavailable | error`; `stop()` → `idle`. `start()` resolves on `ready`, **rejects with `MediaSourceError`** otherwise — but the status/error are also set on the source, so W1 may either `catch` or just read `source.status`/`source.error`. `start()` is idempotent (same promise while requesting; resolved when ready).
* Camera: ideal 1280×720@30, `audio:false`; `deviceId` → `{exact}` (device picker honoured) with an automatic relaxed retry (facingMode only) when that device vanished (`OverconstrainedError`/`NotFoundError`); `facingMode`/`deviceId` read back from track settings; `ended` on the track → `unavailable` ("camera was disconnected…"); `visibilitychange` pauses the element when hidden and resumes when visible (tracks stay live → instant resume); `stop()` during the permission prompt releases the late stream; metadata timeout 8 s → `error`.
* Error mapping: `NotAllowedError/SecurityError → denied`; `NotFoundError/Overconstrained/NotSupportedError/TypeError → unavailable` (also no `mediaDevices` = insecure context → "needs HTTPS or localhost"); `NotReadableError/AbortError/other → error`. Every message ends with the file-fallback hint.
* File: object URL (revoked on `stop()`, source cannot be restarted after — create a new one), `loop/muted/playsInline`, `ready` on `loadedmetadata`, autoplay attempted (the file-picker click is the user gesture; `play()` exposed for a manual retry), `MediaError.code` → readable text, 0×0 (audio-only) → `error`.
* `onFrame`: rVFC with `presentedFrames` from the browser; rAF fallback emits only when `currentTime` advanced and the element is playing. Unsubscribing the last listener disarms the clock.

### `@/runtime`
```ts
startRuntime(deps: RuntimeDeps, options?: RuntimeOptions): AlterFrameRuntime
interface RuntimeOptions { factories?: Partial<RuntimeFactories>; env?: Partial<RuntimeEnv>; sessionSyncMs?: number /*250*/; adaptiveIntervalMs?: number /*500*/ }
interface AlterFrameRuntime extends RuntimeHandle {          // contract: stop, recorder, snapshot, getStats, setSource, injectTracking?
  ready: Promise<void>;                 // renderer initialised + source attached (fast); rejects only if renderer.init throws
  trackerReady: Promise<void>;          // tracker init settled (never rejects); trackerError set on failure
  trackerProgress: number; trackerError: string | null; onTrackerProgress(cb): () => void;   // W1 loading bar
  modules: { stubbed: readonly FactoryName[] };   // [] at full integration (verified in harness: "stubs: none")
  source: FrameSource; frameCount: number; windowOpen: boolean; lastTracking: TrackingFrame | null; lastError: Error | null;
  injectionEnabled: boolean;            // === DEV_BRIDGE_ENABLED
}
getActiveRuntime(): RuntimeHandle | null; subscribeRuntime(cb): () => void
computeCoverFit(video: Size, display: Size): CoverFit; videoToDisplay(p, fit); displayToVideo(p, fit); overlaySizeFor(w, h)
computeGlitch(quad, settings); GLITCH_THICKNESS; resolveFactories(); DEV_BRIDGE_ENABLED
```

**Per-frame order** (driven by `source.onFrame`, skipped until the video has dimensions and the renderer is initialised):
`tracker.setOptions` (only when `mirrored`/`segmentationStride` changed) → size sync → `tracker.update(video, t)` (or injected frame) → `interaction.update(frame, t, scene, settings.interaction)` → events → store (`cycle-persona` → `store.cyclePersona()` unless Director running; `window-open/close` → `handle.windowOpen`) → Director (`start(t)` when `store.directorRunning` flips on, snapshotting the scene; `update(t)` → `store.setScene({ base, persona })` **only** so the store's `hudTintAuto` logic derives `hudTint`; `stop()` restores the snapshot) → `persona.update(frame, scene, t)` → if `hudEnabled`: `hud.setOptions` (only on change), `hud.buildModel(...)`, `hud.draw(model)` → `renderer.render(inputs)` → `perf.sample` → adaptive policy every 500 ms (`setSettings({ quality })` when changed) → session sync every 250 ms (`fps`, `recorderState`, `recorderElapsedMs`, `trackerReady`, only changed keys).

**RenderInputs mapping**: `windowStyle = presetForLayer(scene,'window')` (portrait → `paper-portrait`, masked/suit → `comic` with backdrop), `baseStyle = presetForLayer(scene,'base')` (comic → W5 `COMIC_BASE_PRESET`, no backdrop pass → the real room stays visible as comic; live → `null`), `personaBackdrop` only when `windowStyle.usesBackdrop`, `glitch = computeGlitch(...)`, `time = t/1000`, `mirrored = settings.mirrored`, `videoWidth/Height` = intrinsic.

**Sizing**: `renderer.resize(cssW, cssH, min(devicePixelRatio, quality.maxDpr))` on ResizeObserver + per-frame change detection (dpr changes included); `persona.resize` / `hud.resize` get the **intrinsic video size** (`videoWidth × videoHeight`, 1280×720 before metadata), re-applied when the source changes.

**Lifecycle**: `stop()` is synchronous and idempotent — unsubscribes frames/status, `source.stop()` (tracks stopped, object URL revoked), ResizeObserver disconnected, dev bridge removed, Director stopped, `interaction.reset()`, recorder `stop()` if recording, `tracker.dispose()`, `renderer.dispose()`, registry cleared. Safe under React StrictMode (stop before init completes leaves nothing running — tested). `setSource(next)`: detaches + stops the old source, attaches the new one, resets interaction, starts it if idle, resizes overlays; a recording in progress keeps going (same canvas). Runtime starts an `idle` source itself (never double-starts a `ready`/`requesting` one). A throwing module in one frame is captured in `lastError` and the loop continues. `document.fonts.load('300 16px Inter')` is awaited (≤1.5 s) before the first frame (lead checklist B17).

## 3. Coordinate contract (as agreed with lead, implemented)
* Tracker emits normalized, mirrored coordinates in the **intrinsic video frame**; overlay canvases are sized to that frame; W4 does the **single** cover-fit when presenting. The runtime never remaps landmarks. `viewport.ts` is the shared definition of that cover-fit (`visible` rect, `scale`, offsets, normalized affine) with tests for 16:9→9:16, 4:3→ultra-wide, identity, inverse, and the proof that mirroring commutes with cover-fit. The harness prints the live cover-fit so the lead can check B1 on 390×844 / 1024×1024.
* Mirroring exactly once: W3 mirrors landmarks + mask columns; runtime passes `settings.mirrored` to both `tracker.setOptions` and `RenderInputs.mirrored`; nothing else flips.

## 4. Overrides applied (parent / lead directives)
* **No window global in production.** `window.__alterframe` and `injectTracking` exist only when `import.meta.env.DEV` or `import.meta.env.VITE_E2E === '1'` (static substitution → dead code in the plain build). Verified: `vite build` of the harness → 0 occurrences of `__alterframe`/`injectTracking`/`mockTracking`; `VITE_E2E=1 vite build` → present. **The query string is never read**; `?mockTracking=1` cannot enable injection in production. The `injectTracking` property is only added to the handle object when the gate is open.
* **UI reaches the handle via React/ref**: W1 should keep the `AlterFrameRuntime` returned by `startRuntime` in a ref inside `useRuntime()` and pass it (context) to `shortcuts.ts`/controls; components that cannot see that ref use `subscribeRuntime`/`getActiveRuntime` from `@/runtime`. Nothing in `src/app|src/ui` needs `window.__alterframe`.
* **No persistent storage** in `src/media`/`src/runtime` (grep clean).
* **Glitch default 0** — non-zero only when `settings.thinStripGlitch === true` (read defensively; the key is not in `SettingsSlice`) and `reducedMotion` is false.
* **Director precedence** (checklist B8) — Director > gesture/UI; scene snapshot/restore; `hudTint` derived by the store.
* **W5**: `presetForLayer` / `COMIC_BASE_PRESET` used for the base layer. **W8**: `createHud({ reducedMotion, debugLandmarks, debugDraw: W7 drawLandmarks })`, `setOptions` only on change (keeps the dirty-flag dedupe). **W9**: `createAdaptivePolicy()` per runtime (falls back to `defaultAdaptivePolicy` if absent); recorder stopped on teardown.
* Harness on **port 6212**.

## 5. Stubs — temporary, explicitly documented
`src/runtime/stubs.ts` exists so the loop could compile/run before the other modules landed and so unit tests have deterministic call-order doubles. `factories.ts` resolves **real modules first** via `import.meta.glob(literal, { eager: true })` (statically bundled by Vite when present, no TS dependency on the file existing) and falls back to a stub only for a missing/ill-shaped export, reporting it in `handle.modules.stubbed` and a dev-only warning. In the browser run at hand-off every slot resolved to a real module (`stubs: none`). The static-import equivalent is listed at the bottom of `factories.ts`; the lead may switch to it at integration (same `RuntimeFactories` shape) — recommended once the tree is frozen so type drift is caught by `tsc` rather than at runtime. `stubs.ts` can then be kept for tests only (it is imported by `tests/unit/media/runtimeHarness.ts`).

## 7. Known gaps / notes for integration
* **Cloud sandbox has no camera** — real-camera behaviour (device switching on a phone, unplug) is unit-tested with fakes and must be confirmed by the user on the preview URL.
* `SessionSlice` has no field for "window open"; it is on `handle.windowOpen` only. No store field for tracker download progress either → `handle.trackerProgress` / `onTrackerProgress` (W1 loading bar).
* `RuntimeStats` is the contract shape; richer data is on the handle (`frameCount`, `lastTracking`, `lastError`).
* The runtime keeps a recording alive across `setSource` (same canvas); stopping the runtime finalises it (`recorder.stop()`), result discarded — W1 should stop recording before unmounting if the blob matters.
* Rendering is driven only by presented video frames: a paused/hidden source renders nothing new (HUD blink pauses too). Acceptable; a heartbeat rAF could be added if W1 wants UI-only redraws.
* With real MediaPipe on CPU in headless Chromium the loop runs ~1.5 fps; this is the sandbox, not a product measurement (checklist B25).
* W7 `createInteraction({ cornerSpring })` is left at W7's default (off); enable at integration if the reel's slight lag is wanted.
* The harness screenshot shows W4 compositing the fake camera with the injected quad band; whether the ink outline on the pacman comes from the fake device or from base stylisation on `live` is for the W4 visual check (not W2).
