## Exported API

```ts
// src/render/styles.ts
export const STYLE_PRESETS: Record<StyleId, StylePreset>;
//   'paper-portrait': smooth-h → smooth-v → quantize-clean → ink-paper → grade-paper      usesBackdrop: true
//   'comic':          smooth-h → smooth-v → quantize-warm → ink-comic → halftone → backdrop → grade-comic   usesBackdrop: true
export const COMIC_BASE_PRESET: StylePreset; // id 'comic', usesBackdrop false, comic chain WITHOUT 'backdrop' — for the full-frame base layer
export function presetForLayer(scene: SceneState, layer: 'base' | 'window'): StylePreset | null;
//   window: portrait → paper-portrait, masked/suit → comic;  base: live → null, comic → COMIC_BASE_PRESET

// src/render/shaders/index.ts
export const ALL_PASSES: readonly StylePass[]; // 10 passes
export { smoothH, smoothV, quantizeClean, quantizeWarm, inkPaper, inkComic, halftone, backdrop, gradePaper, gradeComic };
export { PRELUDE, glsl, glslUniformDecls, inkWidthTexels, pxScale, hexToRgb };
```

Every pass declares its own uniforms in the body and provides exactly those via `uniforms(ctx)` (unit-tested: declared set == provided set, GLSL type == value shape). No `#extension`, no derivatives, GLSL ES 3.00 core only. Bodies are orientation-agnostic (no logic depends on whether `v_uv.y = 0` is the top row), so W4's FBO layout does not matter.

### Pass uniforms (all per-frame via `uniforms(ctx)`)

| Pass | Uniforms | Notes |
|---|---|---|
| smooth-h / smooth-v | `u_step` (texels), `u_rangeSigma` 0.14 | 9 taps, gaussian spatial × exp colour-range weights. smooth-h reads `u_video`, smooth-v reads `u_color`. |
| quantize-* | `u_bands` 6, `u_soft` 0.2, `u_saturation` 1.25, `u_tint` vec3, `u_shadowLift` vec3 | warm: tint (1.07,1,0.9), lift (0.08,0.04,0.02); clean: identity |
| ink-paper | `u_inkWidth`, `u_edgeLo` 0.16, `u_edgeHi` 0.42, `u_silhouette` 0.85, `u_inkColor` (#141216), `u_feather` 6 px@720 | reads `u_video`, `u_color`, `u_mask`, `u_backdrop` |
| ink-comic | same minus `u_feather` | never reads `u_backdrop` → valid for base layer |
| halftone | `u_cell` 6 px@720, `u_angle` 15°, `u_maxDarken` 0.25, `u_personWeight` 0.5 | reads `u_mask` (background gets full strength) |
| backdrop | `u_feather` 8 px@720, `u_shadowTint`, `u_shadowEdge` 0.45, `u_rimStrength`, `u_rimColor` | rim is blue for `scene.persona === 'masked'`, pink otherwise |
| grade-* | `u_contrast`, `u_vignette`, `u_grain` 0.03, `u_grainSeed`, `u_lift` | paper: 1.04 / 0.08 / static seed / lift 0.04; comic: 1.15 / 0.22 / seed re-rolled at 12 Hz / 0.02 |

## Look rationale (from reference-analysis.md §2.4, nothing copied)

* **Portrait window**: paper (`PERSONA_TOKENS.paperWhite` via W6 backdrop) + black line-art of the room, person keeps flat saturated colour with soft two-tone bands. `ink-paper` draws Sobel edges everywhere and mixes `u_backdrop` where the mask is background; the mask silhouette gets an extra outline.
* **Comic base**: warm tint, lifted shadows, thick ink, halftone dots on mid-tone walls/cloth, vignette + grain, paper grain re-seeded at 12 Hz for a print-flicker feel.
* **Masked/suit window**: comic chain + `backdrop` (night city / warm paper from W6), two-tone cel shade and a coloured rim at the person edge.

## Assumptions (verified against W4/W2 source as of this handoff)

1. **Prelude**: identical to W4 `src/render/core/prelude.ts` (`highp float/int/sampler2D`, `v_uv`, 4 samplers, `u_resolution`, `u_texel`, `u_time`, `fragColor`). W4 prepends `#line 1`. W10's `tests/e2e/pages/shaders.ts` uses the same prelude.
2. **`PassContext.width/height` = pass output size** (W4 calls `uniforms({ ...ctx, width: w, height: h })` after applying `pass.scale`). `pxScale(ctx, passScale)` normalises against `720 * passScale`. If W4 ever switches to full-res sizes, only `pxScale` needs a change (documented in contract-changes).
3. **`ctx.height` already includes `quality.renderScale`** (W4 `internal` size). `inkWidthTexels` converts to display px (÷ renderScale), clamps to 1.5–2.5, converts back → thinner texel width at low render scales so lines keep the same on-screen thickness.
4. **Mask**: `u_mask.r` person probability, display space, ~256². W4 binds a 1×1 white texture when segmentation is unavailable → paper-portrait degrades to "colour everywhere + line-art" (verified). An unbound/black mask would make paper-portrait all paper + lines (still sane).
5. **Backdrop**: W4 binds paper-white when `personaBackdrop` is null.
6. **First pass input**: `u_color` = ingested (mirrored) video; `smooth-h` samples `u_video` explicitly so it also behaves when the chain is run on any input.
7. **Base layer**: W2 currently passes `STYLE_PRESETS.comic` as `baseStyle`; that includes `backdrop`, so the comic base would replace the room with the persona backdrop. **Use `COMIC_BASE_PRESET` / `presetForLayer(scene, 'base')`** — request filed in `docs/contract-changes.md`.

## Performance (texture fetches per output pixel at 720p, full render scale)

| Pass | fetches | notes |
|---|---|---|
| smooth-h + smooth-v | 2 × 9 at ¼ pixel count ≈ 4.5 | half-res; dominant cost of the old design removed |
| quantize | 1 | |
| ink-paper | 9×2 (Sobel on video+color) + 9 (mask Sobel) + 5 (feathered mask) + 1 (backdrop) + 1 ≈ 34 | heaviest pass; mask is 256² so those taps are cache-hot |
| ink-comic | ≈ 28 | |
| halftone | 2 | |
| backdrop | 1 + 1 + 5 = 7 | |
| grade | 1 | |
| **paper-portrait total** | ≈ 41 | 5 draws |
| **comic (window) total** | ≈ 44 | 7 draws |
| **comic base** | ≈ 37 | 6 draws |

All ALU is trivial (no loops beyond the 4-iteration smoothing loop). On an integrated GPU at 1280×720 this is well under 2 ms per chain; running base comic + window comic = ~13 draws, ~80 fetches/px. Harness timing on SwiftShader (CPU rasteriser, not representative): ~200 ms for the comic chain at 1280×720; the `EXT_disjoint_timer_query_webgl2` path in the runner reports GPU time when a real GPU is present.

Quality knobs the adaptive policy already influences: `renderScale` (all kernels follow it) — nothing else needed from W9.

## Known gaps / notes

* Halftone and vignette are screen-space; inside the hand window they are sampled at the same screen coordinates as the base (matches the reel's "cut-out into a hidden layer").
* Ink thresholds are tuned on the synthetic scene plus sensor-like noise (±4–5 %); real webcams in low light may need `u_edgeLo` nudged up (single constant in `ink.ts`).
* The smoothing is separable (H then V) — not a true 2D bilateral; visually equivalent here, 18 taps vs 81.
* Dev harness page: `/src/render/shaders/__harness__/index.html` (add `?static=1` to stop the animated tile). Never wired into the app.
